## 🚀 Featured Project

### 🧠 StudyMed

**An open-source Telegram study bot designed for medical students.**

[![StudyMed](https://img.shields.io/badge/StudyMed-Open%20Source-2563EB?style=for-the-badge&logo=telegram&logoColor=white)](https://github.com/NaijaCodeClinician/study-med)

StudyMed is my main project and the project I'm currently developing most actively.

It is designed around a simple idea:

> **Turn studying into an active recall loop rather than passive reading.**

### What I'm building

- 🧠 AI-generated medical flashcards
- 📚 Subject and topic organisation
- 🎯 Personalised quizzes
- 📊 Performance and weak-topic tracking
- 🔄 Regeneration and review workflows
- 👥 Community learning features
- 🤖 Telegram-based interaction
- 💾 Persistent user and study data
- 🌐 Eventually, an independent study platform beyond Telegram

### Tech

`Python` · `aiogram` · `SQLite` · `OpenAI API` · `Groq` · `Telegram Bot API` · `asyncio` · `Git/GitHub`
